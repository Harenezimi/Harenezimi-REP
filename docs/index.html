Что умеет платформа

📚

Книги и циклы

Единая карточка для отдельной книги или цикла — с жанрами, описанием и статусом «завершён / продолжается».

🔍

Поиск и фильтры

Поиск по названию и автору, фильтры по жанру, минимальному рейтингу и статусу цикла — прямо в URL.

⭐

Рейтинги

Оценка от 1 до 5 звёзд на пользователя, средний рейтинг и число голосов на каждой карточке.

💬

Комментарии

Живое обсуждение книг и циклов сообществом читателей под каждой записью.

🔗

Где почитать

Блок ссылок «Купить» / «Скачать», который сообщество наполняет само.

🔐

Аккаунты

Регистрация и вход с bcrypt-хешированием паролей, сессии на сервере, личный список «Мои записи».

Эта страница — статичная витрина проекта на GitHub Pages. Само приложение серверное (Node.js/Express + SQLite с сессиями и регистрацией), поэтому здесь оно не запускается «вживую». Чтобы попробовать всё — регистрацию, каталог, оценки и комментарии — склонируйте репозиторий и запустите локально:

npm install && npm run seed && npm start
